// Command Palette

    // System Manual

    • Pick Next Operative

      Restores reverted operatives first, then selects a random operative from the available roster.

      Enter or Space
    • Toggle Main Menu

      Opens or closes the main settings panel.

      Esc
    • Previous Operative

      Undoes the last pick, restores the previous operative, and queues the reverted operative for the next pick.

      U
    • Reboot System

      Resets the selection state, making all operatives available to be picked again.

      R
    • Open Command Palette

      Quickly access all system commands by typing.

      ⌘/ or Ctrl/
    • Open Help Manual

      Displays this list of commands and shortcuts.

      ⌘Shift/ or CtrlShift/
    • Toggle Construct Mode

      Switches to a clean, high-contrast "light mode" interface.

      C
    • Toggle Extraction Mode

      When engaged, picking an operative automatically copies their name or alias to the clipboard.

      E
    • Toggle CRT Mode

      Adds curved-screen shader distortion, scanlines, glow, vignette, a standby preboot light, and a brief monochrome startup on initial CRT loads.

      T
    • Toggle Flat Grid Rain

      Uses uniform pre-distortion rain lanes and hides perspective controls that no longer apply.

      G
    • Toggle Rain Glyph Set

      Switches between the original Matrix code alphabet and the expanded multilingual symbol feed.

      Y
    • Toggle Fullscreen

      Expands the interface to fill the entire screen.

      F
    • Enter/Exit Matrix Mode

      Engages a fullscreen, immersive digital rain experience. Click or press 'M' to exit.

      M
